# 値の表現

- 金額・価格・数量は最小単位の整数で持つ（ADR 0036）。金額は通貨の最小単位（円は1円、ドルは1セント）、価格と数量は銘柄ごとの最小単位（BTC/JPY は価格が1円、数量が 1e-8 BTC = satoshi）。単位の定義は `packages/core/src/instrument.ts` に置き、`money.ts` の計算に銘柄を渡す。単位の定数を計算の中に直接書かない
- 時刻は UTC のエポックミリ秒の整数で持ち、表示時に JST へ変換する
- 画面に出す金額・数量には単位を付ける（円は値の後ろに「円」、BTC は「 BTC」）。見出しに単位を書いて値を裸にしない。入力欄はラベルに「（円）」のように書く。チャートの軸と、チャート上の始値・高値・安値・指標の値は価格と分かるので付けない（終値には付ける）
