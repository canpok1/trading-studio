# バックテスト

取り込んだ過去データで、条件セットの売買を模擬する。

## 実行条件

- 条件セット。保存済みの戦略から変えて試せるよう、戦略 ID ではなく条件の中身を受け取る（元の戦略 ID も持つ）
- 期間（終了の時刻は含まない）、初期資金（円）、手数料率（指値・成行を別々に。0〜10%）
- 足の粒度は条件セットの粒度を使う

## 実行前の検証

- 条件セットと実行条件の入力検証を通らなければ実行しない
- 期間に取り込んだ足が無い、または取り込んだ足が戦略の粒度より粗い場合は実行しない
- 期間内の戦略の粒度の足に欠損があれば確認を求める。「欠損を飛ばして実行」すると、欠けた足は無いものとして進める
- 指標の計算に使うため、期間より前の足も読む（EMA は本数の10倍）

## 実行

- サーバー内の別スレッド（Bun の Worker）で計算し、API の応答を止めない。進捗の取得と中止ができる
- 同時に実行できるのは1つ。実行中に新しい実行は受け付けない
- サーバーが途中で止まった実行は、次の起動時に失敗として残す

## 結果

- 実行時の条件の写しを持つ。後で戦略を編集・削除しても結果の条件は変わらない
- 成績・注文・往復の取引・判断ログ・期間内の足の終値を保存する。過去の実行はすべて残す
- 注文の一覧は新しい順で、約定だけに絞れる
- 結果の条件は、元の戦略へ上書きするか、新しい戦略として保存できる。新しい戦略として保存すると、その結果の元の戦略は新しい戦略になる

## 画面

- 実行画面で変えた条件・期間・資金・手数料率は、戦略には保存せず、ブラウザに残す。「保存済みに戻す」で戦略の条件へ戻す
- 足の粒度は戦略の粒度を表示するだけで、変えるには戦略設定で変える
- 実行中は他の画面へ移っても処理が続き、下部タブ・サイドバーに印を出す。バックテストの画面にいれば終わったときに結果へ移り、他の画面にいれば知らせる
- 結果の条件が元の戦略の保存済みの条件と同じなら、「この条件を戦略に保存」は出さない
