# ホーム

アプリを開いたときの最初の画面。タブ（PC はサイドバー）の先頭に置く。戦略ごとの状況と操作は戦略の画面（`docs/strategy-page.md`）で行う。

## 配置

- 上から、市場評価、チャート、戦略の一覧の順に置く
- 戦略の一覧は戦略の画面の一覧（`docs/strategies.md`）と同じ行で、押すと戦略の画面へ移る。戦略が1つも無ければ、その旨と戦略の画面への導線を出す
- 価格の収集が止まっている間だけ、先頭に「何が起きたか・止まった時刻・自動で再接続する予定」を出す

## 内容

- 市場評価とチャートは戦略の画面と同じ（`docs/strategy-page.md` の「内容」「チャートの市場評価」）。ただし戦略を選んでいないので、注文の印・買値の線・発動価格は出さず、EMA・ボリンジャーバンド・RSI は戦略の条件ではなく保存した本数か既定の値を使う

## 以前の URL

- 戦略ごとのタブを持っていたころの URL は戦略の画面へ移す。`/home?strategy=2` は戦略の id、統合前の `/home?run=3` は口座の id（`docs/trading.md`）として引き継いだ戦略の画面へ。見つからなければホームのまま
- `/home?mode=paper` のようなモードの指定は無視してホームを開く
