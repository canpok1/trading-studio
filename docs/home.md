# ホーム

アプリを開いたときの最初の画面。タブ（PC はサイドバー）の先頭に置く。

## 配置

- 最上部に運用（`docs/trading.md`）ごとのタブを作った順に並べ、右端に「＋」を置く。並びきらなければタブを横にスクロールする。稼働中のタブは名前の前に緑の点、リアルのタブは名前の後ろに「リアル」の印を出す
    - タブは URL（`/home?run=2` など）に持つ。指定が無ければ稼働中の最初のタブ、どれも止まっていれば先頭で開く。`?mode=paper` のように以前のモードの指定で開いたときは、そのモードの最初のタブで開く
    - 自動取引設定・口座情報・成績・注文・約定とチャートの注文の印・保有の買値の線は、選んでいるタブのものを出す。市場評価とチャートの価格はタブに関わらず同じ
    - リアルはまだ動かせないため、リアルのタブは口座情報・成績・注文・約定を出さない
    - 「＋」でタブを追加する。モード（デモ/リアル）・運用する戦略・名前（既定は選んだ戦略の名前。書き換えるまで戦略に合わせる）を選ぶ。条件が足りない戦略は選べない。上限（5つ）に達したら「＋」を押せない。リアルのタブは1つまで（実口座は1つのため）
    - 追加したタブへ移り、結果は画面下に短く出す
- タブの下に要点（通算損益・含み損益・センチメント・リスクの小さなカードと、自動取引のカード）、その下にチャート、成績・口座情報、注文・約定の順に置く。よく変わり気になる値を上に、たまにしか見ないものを下にするため
    - スマホ幅: 自動取引のカードを1行で置き、その下に要点を 2×2。以降は1列で縦に並べる
    - PC 幅: 要点を横一列に並べ、自動取引のカードは右端に置く（画面が十分に広くなければ要点の上に1行で置く）。チャート（高さ 480px、RSI を出すと 640px）と注文・約定は2列ぶんの幅、成績｜口座情報は2列（同じ段は高さを揃える）
    - リアルのタブは通算損益・含み損益を出さない
- パネルの上端に見出しを置く。チャートの見出しは「チャート」で、操作の説明は横の「？」
- チャートの表示の切り替え（足の粒度・背景・表示）はチャートのパネルの見出しの下に1行で置く。足の粒度と背景はプルダウン、線の表示は「表示」のボタンで開くメニュー（外を押すか Esc で閉じる）

## 内容

- 現在値はチャートで見る（今のレートの線と価格の軸の「現」の値、上端の値の行）。別の見出しは置かない
- 上端の値の行が最新の足を表示しているときだけ、終値の右に24時間の変化率を出す（上がれば緑・下がれば赤）。過去の足を指している間は出さない
- 5秒ごとに最新の価格を問い合わせ、チャートの最後の足に反映する。足そのものは1分ごとに取り直す。画面が非表示の間は止める
- 価格の収集が止まっている間だけ、画面の先頭に「何が起きたか・止まった時刻・自動で再接続する予定」を出す
- 自動取引設定（`docs/trading.md`）: タブのオンオフのスイッチ・稼働中/停止中・運用する戦略の名前を1行で出す。説明文や本日の損失・次の判定時刻は出さない
    - 運用する戦略の選択・「タブの名前を変える」「タブを削除」は、たまにしか使わないので「⋯」で開くタブの設定に入れる
    - オンオフと運用する戦略はタブごと。ほかのタブが稼働中でも、このタブはオンにできる
    - オンにするときは確認（タブ名・戦略名と次の判定時刻）を出し、「開始する」で始める。オフは確認なしで即時。結果は画面下に短く出す
    - 「タブを削除」は、オフのときで、タブが2つ以上あるときだけ出す。確認で、未約定の注文を取り消し保有を捨てること（あるときだけ）と、注文・判断の記録は分析用のエクスポートに残ることを出す。削除したら稼働中の最初のタブ（無ければ先頭）へ移る
    - オン中と、保有か未約定の注文がある間は運用する戦略を変えられない（`docs/strategies.md`）。保有で止めているときはその旨を出す
    - リアルのタブのスイッチは押せず、「リアル取引はまだ使えない」と出す
    - 条件が足りない（戦略の入力検証を通らない）戦略は運用する戦略に選べない
    - 1日の損失上限に達して買いを止めている間と、価格の収集が止まって判定を待っている間だけ、その旨を出す
    - 状態は5秒ごとに問い合わせる
- 通算損益（口座のリセット以降）: 開始時の資金からの損益（円・%）。確定した分と保有の含み損益を合わせたもの（総資産 − 開始時の資金）。評価のバッジと、ガチホの損益率を添える
- 含み損益（タブの口座）: 保有中の全ロットの合計。手数料を含めず、今の価格で評価する。保有のロット数を添える。保有が無ければ「—」
- 口座情報（タブの口座）: 総資産（大きく）・現金・保有・平均取得。保有があればロット数を添え、押すとロットごとの買値・数量・買った日時・含み損益の一覧を出す
    - 自動取引がオフのときだけ「口座をリセット」を出す。確認で開始時の資金（既定 100万円）を入れてリセットする
- 成績（口座のリセット以降）: 集計の開始時刻・確定損益・勝率（勝敗）・最大DD（期間）・PF・取引回数（平均保有）。数え方は `docs/trading.md` の「成績」。5秒ごとに読み直す
- 注文・約定: タブの注文を10件ずつ、絞り込み・日ごとのまとめ・件数と実現損益の合計つきで出す（`docs/trading.md` の「注文・約定の一覧」）。行を押すと注文の詳細
- チャートにタブの注文・約定・取消の印を出す（バックテスト結果と同じ形）。印を押すと注文の詳細。成行の注文中は価格が無いので今の価格に置く
- 注文と保有は5秒ごとに問い合わせる
- チャートは足の粒度を切り替えられる。既定は日足で、最後に選んだ粒度をブラウザに保存し、バックテスト結果のチャートと共有する。戦略の条件の足は見ない（条件ごとに足が違い、選ぶ側で調整できるため）
- 期間の切り替えは置かない。粒度ごとに2万本に収まる最も長い期間（全期間・1か月・1週・1日の順）を読み込み、最初は直近1日か足 60 本ぶんの長いほう（最低30本）を見せる。残りはピンチ・ホイール・＋−のボタンで拡大・縮小して見る
- ＋−は最新の足が見えていれば右端を保ち、見えていなければ中央を保って拡大・縮小する。「最新へ」で拡大の度合いを保ったまま最新の足へ戻る（最新が見えている間は押せない。バックテスト結果のチャートと共通）
- −・＋・「最新へ」のボタンは、PC では上の値の表示の右、スマホでは上の値の表示の下（チャートのすぐ上）に右寄せで置く（バックテスト結果のチャートと共通）
- 今のレートを灰色の破線と、価格の軸の「現 13,000,000」のような値で出す（5秒ごとに更新）
- 保有中のロットの買値を、ロットごとに買いの矢印と同じ色の実線と、価格の軸の「買 12,650,000」のような値で出す。縦の範囲は買値を含めて決め、足から離れた買値も画面に入れる（価格の軸をドラッグして縦に拡大すれば外せる）。「表示」のメニューの「買値」で出す・隠すを切り替えられ、隠すと線・軸の値とも消え、縦の範囲にも含めない。最初は出し、選んだものはブラウザに保存する
- 出来高を価格の下（市場評価の帯のすぐ上）に灰色の棒で出し、指した足の値を上の値の表示に「出来高 112.594 BTC」のように出す。上げ下げは塗り分けない（向きはローソク足で分かる）。「表示」のメニューの「出来高」（バックテスト結果は「表示」の行のボタン）で出す・隠すを切り替えられる。最初は出し、選んだものはブラウザに保存してバックテスト結果のチャートと共有する。出来高を持たない足（バックテストの結果に残した足）には棒を出さない
- 線の名前はチャートの内側に出すと最新の足に重なるので、1文字にして軸の値の前に付ける。軸の値どうしが重なるときは「現」を線の位置に置き、「買」を上下へずらす
- EMA の線（2本まで）、ボリンジャーバンド（上限・下限の実線と中央の点線）と RSI の小窓（価格の下に 0〜100、下・上のしきい値を点線で引く）を出せる。指した足の値を上の値の表示に出す。以下はバックテスト結果のチャートと共通
    - 「EMA」「BB」「RSI」のボタン（ホームは「表示」のメニューの中）で表示を切り替える。最初は、戦略で使っているか本数を変えて保存していれば表示し、そうでなければ隠す
    - 本数は横の歯車から変えられる（EMA は 2〜500 本を1〜2本、ボリンジャーバンドは 2〜500 本と σ 0.1〜5、RSI は 2〜100 本としきい値 1〜99）。変えた値はブラウザに保存し、ホームとバックテスト結果で共有する。「戦略の値に戻す」（戦略で使っていなければ「既定の値に戻す」）で保存を消す
    - 変えていなければ戦略の条件の値を使う。EMA は（クロス・終値との位置の条件を合わせて）短い方から2本、RSI は（RSI・RSI のクロスの条件を合わせて）最も短い本数と、その本数の条件のしきい値の最小・最大（1つだけなら 50 未満は下側、それ以外は上側に置き、もう片方は既定）、ボリンジャーバンドは最も短い本数（同じなら σ が小さい方）。戦略で使っていなければ既定の値（EMA 20・50 本、ボリンジャーバンド 20 本・2σ、RSI 14 本・30/70）
    - 本数は選んでいる粒度の足で数える。条件の足以外の粒度でも出す
- 価格のデータがまだ無ければ「収集を始めたばかりでデータが無い」を出す
- 市場評価: 今の評価（センチメント・リスク）を1枚ずつ、平均点とともに出す。押すとニュース画面へ移る。足と一緒に1分ごとに取り直す

## チャートの市場評価

- 足ごとの判定を、選んだ判定1つはチャートの背景に薄く、残り1つはチャートの下の帯に濃く塗る。背景の既定はセンチメント
- 背景は「なし」も選べる。なしのときは背景を塗らず、両方の判定を下の帯に並べる
- 背景は「背景」のプルダウン（バックテスト結果はボタン）か、下の帯をタップして選ぶ（タップした帯の判定が背景になる）。選んだものはブラウザに保存し、再読み込みしても保つ（バックテスト結果のチャートと共通）
- 足の判定は、その足の終わりの時刻に今の評価ルールで計算する（まだ終わっていない足は今の時刻）。評価ルールを変えると過去の足の判定も今のルールで出し直す
- 採点の記録が始まる前の足は塗らない。どの足にも判定が無ければ背景・帯・切り替えを出さない
- 凡例に判定の区分と色を出す。チャートの上の値の表示には、指した足の判定を観点名付き（「センチメント 中立」「リスク 警戒」）で出す
