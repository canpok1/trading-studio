# ホーム

アプリを開いたときの最初の画面。タブ（PC はサイドバー）の先頭に置く。チャート1つと、稼働中の戦略のカードを並べて比べる。戦略ごとの詳しい状況と操作は戦略の画面（`docs/strategy-page.md`）で行う。

## 配置

- 上にチャート、下に「稼働中の戦略」のカードを置く
- スマホはカードを2列。チャートを戦略の画面より低くし、最初の画面に4枚のカードの名前と値が入るようにする。そのためスマホではチャートの上の値の表示から出来高・判定の読み取りを省く
- PC はチャートを全幅にし、その下にカードを横に並べる（4〜5枚で1行）
- 価格の収集が止まっている間だけ、先頭に「何が起きたか・止まった時刻・自動で再接続する予定」を出す

## チャート

- 戦略の画面のチャートと同じ（`docs/strategy-page.md` の「内容」「チャートの市場評価」）
- 見出しの右に今の市場評価（センチ・リスク。PC は平均点も）を出す。押すとニュース画面へ
- 印（注文の印・買値の線・発動価格）は、カードで選んだ1つの戦略のものを描く。どの戦略の印かは選択中のカードの「チャート」の札で分かるので、チャートには戦略名を出さない。EMA・ボリンジャーバンド・RSI の既定もその戦略の条件に従う
- 選んだ戦略の候補が2つ以上（`docs/adr/0037`）なら、チャートの見出しの下で見る銘柄を切り替えられる。既定は保有中の先頭の銘柄、無ければ候補の先頭。価格・足・市場評価・印はその銘柄のもの。候補が1つの戦略はその銘柄、戦略が無ければ BTC/JPY を出す
- 選んだ戦略はブラウザに保存する。選んだ戦略がカードに無くなったら（止めた・消した）、その間は先頭のカードの戦略を描く（選んだ戦略がまたカードに出れば戻る）。カードが無ければ印は描かない

## 稼働中の戦略

- 出すのは、デモで、自動取引がオンの戦略と、オフでも保有か未約定の注文がある戦略（含み損益が動くため）。作った順に並べ、値の順には並べ替えない（切り替えるたびに位置が動き、押し間違えるため）
- 「比べる値」のプルダウンで、カードの大きな値を 通算損益・含み損益・確定損益・勝率・PF・最大DD・取引回数 から選ぶ。選んだ値はブラウザに保存する
- カードには、名前・比べる値・補足（通算損益なら損益率、勝率なら勝ち負けの回数など）・次の動きを出す。大小を示す棒は出さない（値で比べられ、棒の基準が値ごとに違って分かりにくいため）
    - 次の動きは、戦略の画面の次の動き（`docs/strategy-page.md`）のうち優先度の高い上位2つを出す。円の差・今の値は幅が足りないので出さず、戦略の画面で出す。スマホ幅の2列では種類のバッジから買いの名前も外し、価格のきっかけなら1行に収まるようにする（同じ種類が2つ並ぶと買いを見分けられないが、2列は省略して押しやすさを取る表示のため。名前は1列と戦略の画面で見る）。何も無ければ「次の動きなし」、オフの戦略は「停止中のため新しい注文は出さない」と注文中のもの、今の価格が取れなければ「価格が取れず試算できない」と出す
    - オフで保有か未約定の注文がある戦略は「停止中（保有・注文あり）」と添える
- スマホ幅は「比べる値」の左のボタンで並べ方を 2列・1列 から選ぶ。選んだ並べ方はブラウザに保存する。PC 幅は列が多く名前も見えるので切替を出さない
    - 2列（既定）は押しやすさを優先し、名前は1行で切る
    - 1列は名前の見分けやすさを優先する。名前を1行目の全幅に置いて切らずに出し（入らなければ折り返す）、その下に次の動き2件（左）と、値・補足の2行（右）を並べて縦に伸びるのを抑える
    - 候補が2つ以上の戦略は、次の動きに銘柄（ETH など）を添える。保有中の銘柄から順に、銘柄ごとの優先度の高いものを1つずつ交互に取る（1つの銘柄の動きでカードが埋まらないように）
- カードを押すとチャートの印をその戦略に切り替える。選んだカードは枠を太くして「チャート」の札を付け、「詳しく ›」から戦略の画面へ移る（押す操作と移る操作を分ける）
- カードに出ない戦略があれば、下に「停止中 N 件は「戦略」で見られる ›」を出し、戦略の一覧へ移る
- カードに出す戦略が無ければ、その旨と戦略の一覧への導線を出す（戦略が1つも無ければ「戦略を作る」）
- カードの値は `GET /api/trading/summaries` でまとめて読み、5秒ごとに読み直す。カードの数だけ問い合わせない

## 以前の URL

- 戦略ごとのタブを持っていたころの URL は戦略の画面へ移す。`/home?strategy=2` は戦略の id、統合前の `/home?run=3` は口座の id（`docs/trading.md`）として引き継いだ戦略の画面へ。見つからなければホームのまま
- `/home?mode=paper` のようなモードの指定は無視してホームを開く
