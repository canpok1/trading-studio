# ホーム

アプリを開いたときの最初の画面。タブ（PC はサイドバー）の先頭に置く。

- 見出しに `BTC/JPY · Coincheck · 現在時刻`、現在値と24時間の変化率を出す。現在値は上がれば緑・下がれば赤で一瞬光る
- 5秒ごとに最新の価格を問い合わせ、チャートの最後の足に反映する。足そのものは1分ごとに取り直す。画面が非表示の間は止める
- 価格の収集が止まっている間だけ、現在値の下に「何が起きたか・止まった時刻・自動で再接続する予定」を出す
- 運用する戦略を選べる（フェーズ2では常に変更できる）
- チャートは期間（1日・1週・1か月・全期間）と足の粒度を切り替えられる。粒度の既定は運用する戦略の粒度、戦略が無ければ期間に合わせる（1日=1分足、1週=15分足、1か月=1時間足、全期間=日足）。足が5万本を超える組み合わせは選べない
- EMA の線は、運用する戦略に EMA の条件があり、戦略の粒度を選んでいるときだけ出す（別の粒度では本数の意味がずれるため）
- 価格のデータがまだ無ければ「収集を始めたばかりでデータがない」を出す
