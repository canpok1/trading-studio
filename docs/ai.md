# AI判定画面

ニュースの採点から出した判定と、その材料・設定を見て変える画面（`/ai`）。収集・採点・集計の仕様は `docs/news.md` と下の「集計」。

## 集計

- 判定は保存せず、見るたびに採点済みの点数から計算する。集計ルールを変えると、過去の判定もそのルールで計算し直す
- 評価時刻より後に採点した点数は使わない。新しさは公開時刻で測る（取得時刻より後なら取得時刻）
- 期間内の点数を、半減期ごとに重みが半分になる加重平均にし、整数に丸めてしきい値で判定にする。null（関係なし）は入れない。対象が無い観点は中立（レンジ・平常・0）
- 集計ルール（期間・半減期は 1〜168 時間の整数、しきい値は 0〜100 の整数）は、トレンドは 下落 < 上昇、リスクは 警戒 < 危機、センチメントは −2 < −1 ≦ +1 < +2 の順でなければ保存できない

## 画面

- タブ（スマホの下部）は ホーム・バックテスト・AI判定・戦略設定・その他。過去データはスマホでは「その他」の中、PC ではサイドバーに置く
- 上部に今の判定3つ（判定・平均点・何件から算出・しきい値の帯）と、集計の説明・時点
- 収集・採点が止まっている間だけ、判定の下に何が起きたかといつからかを出す。一部の取得元だけ失敗しているときも取得元ごとに出す
- 5秒ごとに判定・ニュース・収集と採点の状態を問い合わせる。画面が見えていない間は止める
- 表示中のタブは URL（`?tab=`）に持つ

### ニュースごと

- 新しい順に最大100件。公開時刻・取得元・見出し（原文、記事へのリンク）
- 採点済み: 観点ごとの点数（— は関係なし）・理由・採点時刻・版・モデル・集計での重み。期間外は「集計の対象外」
- 未採点: 採点中（採点が止まっていれば「未採点」）。再試行待ち: 失敗の理由と次の自動再試行の時刻。採点に失敗: 理由と再試行ボタン。古いため採点しないもの: 集計の対象外

### 集計ルール

- 期間・半減期・しきい値を編集する。入力の誤りは項目の下に出し、保存できない
- 入力が正しい間は「この設定での今の判定」を出す（保存しない）
- 元に戻す・保存。保存すると次の判定から反映する

### プロンプト

- 固定のひな形（編集不可）と、差し込む場所
- 使用中の版の採点の基準を元に編集する。「最新のニュースで試す」は保存も集計への反映もしない
- 「vN として保存」は新しい版を足すだけで、使用中の版は変えない。版の説明は任意（空なら「画面から編集」）
- 版の履歴から「使用する」で切り替える。「差分」で選んだ版から使用中の版への差分を行単位で出す

### 収集と採点

- 取得元の一覧（名前・言語・URL・最後に取得した時刻か失敗の理由）、有効/無効の切り替え、削除（確認あり）
- 取得元の追加（名前・RSS の URL・言語）
- 収集間隔（5〜1440 分）
- 採点に使うモデル
