# 戦略

戦略は名前を付けて保存する条件セット。複数持てる。画面は「戦略」。

## 条件セット

- 足の粒度を1つ持つ。EMA・RSI の本数・直近 N 本・指値を取り消すまでの本数はこの粒度の足で数える
- 判定の間隔をポジションなし・ありで別々に持つ（1〜999 の整数と、秒・分・時間）
- 1回の注文量は 0.001〜1 BTC。約定した買い1件がこの量の1ロットになる
- 最大ポジション数（1〜10 の整数）。同時に持てるロットの数で、未約定の買い注文も数える。既定は 1。持たない保存済みの戦略・バックテスト結果も 1 で読む
- 1日の損失上限（円、1〜1億の整数）。既定は 30,000 円（仮置き）。持たない保存済みの戦略・バックテスト結果もこの既定で読む
- 条件は「買い注文する条件」「売り注文（利確）する条件」「売り注文（損切り）する条件」の3グループに任意個入れる。グループごとに「すべて満たす」か「どれか1つ」を選ぶ
- 買いと損切りは1つ以上の条件が必要。利確は空でもよい

| 条件 | 内容 | 範囲 |
|---|---|---|
| EMA のクロス | 短期 EMA が長期 EMA を、前の足から今の足の間に上抜け・下抜けた（等しいだけではクロスとしない） | 2〜500 本、短期 < 長期 |
| 直近の高値・安値の突破 | 終値が、今の足を除く直近 N 本の最高値を上回った・最安値を下回った | 2〜1000 本 |
| RSI | 判定時の RSI（Wilder 方式、終値で計算）が N 以上・以下。どのグループでも使える | 期間 2〜100 本、しきい値 1〜99 の整数 |
| 買値からの % | 判定時の現在値が買値から N% 以上上がった・下がった。売りのグループだけで使える | 0.1〜100% |
| トレンド / リスク / センチメント判定が指定のどれか | 判定時の AI 判定（`docs/news-page.md`）が、選んだ値のどれかである。どのグループでも使える。判定がまだ無ければ判定しない | 1つ以上選ぶ |

- RSI の条件を追加するときの既定は、買いでは「14 本が 30 以下」、売りでは「14 本が 70 以上」
- AI 判定の条件を追加するときの既定の選択は、買いでは良い側（トレンドは上昇・レンジ、リスクは平常・警戒、センチメントは 0 以上）、売りでは悪い側（下落・危機・−2）

## 注文

- 買いの注文は「買い注文する条件」に行の並び（1〜10 行）で持つ。条件が成立すると、行の数だけ同時に出す
    - 行ごとに指値か成行を選ぶ。成行は1行だけで、先頭に置く。指値と混ぜてよい
    - 指値：現在値から N% 下（0 以上 100 未満、0.01 刻み。円未満は切り捨て）に出す。下の行ほど大きい % にする（同じ値・逆順は保存できない）。指値の行は全件同じ M 本（1〜100）のあいだ約定しなければ取り消す。一部が約定しても残りは期限まで置く
    - 成行：判定時の現在値で見積もった注文額に資金が足りなければ出さない。バックテストでは次の足の始値で約定し、その時点で手数料込みの約定額に資金が足りなければ取り消す
    - 空き枠（最大ポジション数 − 保有ロット − 未約定の買い）が行の数より少なければ、空きの数だけ先頭から出す
    - 資金は行の順に見積もり、足りなくなった行から先は出さない。未約定の買いの額（手数料込み）は資金から除いて見る。同時に出した買いが先に約定して足りなくなったら、約定時に取り消す
    - 既定は指値・0.1% 下・3 本の1行。行を持たない保存済みの戦略・バックテスト結果は、持っている注文方法の1行として読む
- 買いの注文が1件でも約定待ちの間は、新しい買いを出さない
- 最大ポジション数が 2 以上なら、買いの条件が前回の判定で成立していたときは買わない（RSI 30 以下のような条件が続く間に、約定のたびに次を買って枠が埋まるのを防ぐ）。一度外れてから再び成立したら買う。最大ポジション数が 1 の戦略には効かせない（今までどおり、売った直後に条件が続いていれば買い直す）
- 売りはロットごとに判定し、成立したロットだけ成行で全量を売る
    - 「買値からの %」はそのロットの買値で見る。EMA・RSI・AI 判定の条件はロットに依らないので、成立すると全ロットを売る
    - 利確と損切りが同じ判定で両方成り立ったロットは損切りを優先する
    - 売りが約定待ちのロットは判定しない
- 同じ判定で売りと買いが両方成立したら両方出す。空き枠は売る前の保有で数え、売りで空く枠は次の判定から使う
- 判定の間隔は、ロットを1つでも持っていれば「ポジションあり」を使う

## リスク上限

- その日（JST 0:00 区切り）に売って確定した損益（手数料込み）の損が1日の損失上限に達したら、新しい買い注文を出さない。翌 0:00（JST）に再開する
- 含み損は数えない。売り（利確・損切り）は止めない。自動取引はオンのまま
- 戦略の条件とは別に、売買の1ステップ（`docs/trading.md`）の中で注文を出す手前で検査する。バックテストにもペーパーにも同じように効く
- 買いを止めた理由は判断の記録に残す
- 同時の保有は「1回の注文量 × 最大ポジション数」までに収まるので、保有量の上限は別に持たない。急落で全ロットが同じ判定で損切りされると、1日の損失上限を1回で大きく超えることがある

## ひな形

新しい戦略は、ひな形（空の戦略・トレンド追随・レンジ逆張り）か、保存済みの戦略の複製から作る。ひな形の最大ポジション数は 1。買いの注文はトレンド追随だけ成行の1行（上抜けで買うため、指値では取り逃がしやすい）、ほかは既定の指値の1行。作った後はひな形・複製元と切り離される。

## 保存

- 名前は 1〜40 文字で、戦略どうしで重複できない
- 条件は入力検証を通ったものだけ保存できる
- 削除しても過去のバックテスト結果は残る

## 運用する戦略

- 保存済みの戦略から1つを「運用する戦略」に選ぶ。未選択でもよい。サーバーに保存する
- 運用する戦略を削除すると未選択に戻る
- フェーズ2ではホームのチャートの EMA 線と粒度の既定に使う。自動取引（フェーズ4）もこの選択を使う
