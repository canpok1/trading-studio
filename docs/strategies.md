# 戦略

戦略は名前を付けて保存する条件セット。複数持てる。画面は「戦略」。

## 条件セット

- 足の粒度を1つ持つ。EMA の本数・直近 N 本・指値を取り消すまでの本数はこの粒度の足で数える
- 判定の間隔をポジションなし・ありで別々に持つ（1〜999 の整数と、秒・分・時間）
- 1回の注文量は 0.001〜1 BTC
- 条件は「買い注文する条件」「売り注文（利確）する条件」「売り注文（損切り）する条件」の3グループに任意個入れる。グループごとに「すべて満たす」か「どれか1つ」を選ぶ
- 買いと損切りは1つ以上の条件が必要。利確は空でもよい

| 条件 | 内容 | 範囲 |
|---|---|---|
| EMA のクロス | 短期 EMA が長期 EMA を、前の足から今の足の間に上抜け・下抜けた（等しいだけではクロスとしない） | 2〜500 本、短期 < 長期 |
| 直近の高値・安値の突破 | 終値が、今の足を除く直近 N 本の最高値を上回った・最安値を下回った | 2〜1000 本 |
| 買値からの % | 判定時の現在値が買値から N% 以上上がった・下がった。売りのグループだけで使える | 0.1〜100% |
| トレンド / リスク / センチメント判定が指定のどれか | 判定時の AI 判定（`docs/ai.md`）が、選んだ値のどれかである。どのグループでも使える。判定がまだ無ければ判定しない | 1つ以上選ぶ |

- AI 判定の条件を追加するときの既定の選択は、買いでは良い側（トレンドは上昇・レンジ、リスクは平常・警戒、センチメントは 0 以上）、売りでは悪い側（下落・危機・−2）

## 注文

- 買いは現在値より 0.1% 下の指値で出し、3 本のあいだ約定しなければ取り消す。資金が足りなければ出さない
- 売りは成行でポジションを全部売る
- 利確と損切りが同じ判定で両方成り立ったら損切りを優先する
- 自分の注文が約定待ちの間は判定しない

## ひな形

新しい戦略は、ひな形（空の戦略・トレンド追随・レンジ逆張り）か、保存済みの戦略の複製から作る。作った後はひな形・複製元と切り離される。

## 保存

- 名前は 1〜40 文字で、戦略どうしで重複できない
- 条件は入力検証を通ったものだけ保存できる
- 削除しても過去のバックテスト結果は残る

## 運用する戦略

- 保存済みの戦略から1つを「運用する戦略」に選ぶ。未選択でもよい。サーバーに保存する
- 運用する戦略を削除すると未選択に戻る
- フェーズ2ではホームのチャートの EMA 線と粒度の既定に使う。自動取引（フェーズ4）もこの選択を使う
