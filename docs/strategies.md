# 戦略

戦略は名前を付けて保存する条件セット。複数持てる。画面は「戦略」。

## 条件セット

- 戦略全体の足は持たない。本数で数える項目は、項目ごとに数える足を持つ（`docs/adr/0018`）
    - 足を持つ条件: EMA のクロス・直近の高値・安値の突破・RSI・RSI のクロス・終値と EMA の位置・EMA の傾き・ボリンジャーバンド・買ってからの本数。画面では条件の頭で足を選ぶ（例: 「日足で RSI 14 本が 30 以下」）。新しく足す条件の既定は1時間足
    - 足を持たない条件: 買値からの %・トレーリングストップ・市場評価
    - 指値を取り消すまでの本数と、損切り後に買わない本数も、それぞれ数える足を持つ
    - 足を持つ前に保存した戦略・バックテスト結果は、戦略の足をこれらすべての足として読む
- 判定の間隔を保有なし・保有中で別々に持つ（1〜999 の整数と、秒・分・時間）
- 1回の注文量は 0.001〜1 BTC。約定した買い1件がこの量の1ロットになる
- 最大ロット数（1〜10 の整数）。同時に持てるロットの数で、未約定の買い注文も数える。既定は 1。持たない保存済みの戦略・バックテスト結果も 1 で読む
- 1日の損失上限（円、1〜1億の整数）。既定は 30,000 円（仮置き）。持たない保存済みの戦略・バックテスト結果もこの既定で読む
- 損切り後に買わない本数（足と、0〜1000 の整数）。既定は 0（止めない）。持たない保存済みの戦略・バックテスト結果も 0 で読む（「リスク上限」）
- 条件は「買い注文する条件」「売り注文（一部利確）する条件」「売り注文（利確）する条件」「売り注文（損切り）する条件」の4グループに任意個入れる。グループごとに「すべて満たす」か「どれか1つ」を選ぶ
- 買いと損切りは1つ以上の条件が必要。一部利確と利確は空でもよい。一部利確の条件を持たない保存済みの戦略・バックテスト結果は空として読む

| 条件 | 内容 | 範囲 |
|---|---|---|
| EMA のクロス | 短期 EMA が長期 EMA を、前の足から今の足の間に上抜け・下抜けた（等しいだけではクロスとしない） | 2〜500 本、短期 < 長期 |
| 直近の高値・安値の突破 | 終値が、今の足を除く直近 N 本の最高値を上回った・最安値を下回った | 2〜1000 本 |
| RSI のクロス | 判定時から直近 M 本以内のどれかの足で、RSI が N を上抜けた（前の足 < N ≦ その足）・下抜けた（前の足 > N ≧ その足）。M が 1 なら今の足だけ。どのグループでも使える | 期間 2〜100 本、しきい値 1〜99、M 1〜100 本の整数 |
| 終値と EMA の位置 | 判定時の終値が EMA(N) より上・下（等しいときは成立しない）。どのグループでも使える | 2〜500 本 |
| EMA の傾き | 判定時の EMA(N) が M 本前の EMA(N) から X% 以上上がっている・下がっている。X が 0 なら向きだけを見る（変化が 0 のときはどちらも成立しない）。どのグループでも使える | 2〜500 本、M 1〜500 本、X 0〜100%（0.01 刻み） |
| RSI | 判定時の RSI（Wilder 方式、終値で計算）が N 以上・以下。どのグループでも使える | 期間 2〜100 本、しきい値 1〜99 の整数 |
| ボリンジャーバンド | 判定時の終値が、N 本・Kσ のバンドの上限以上・下限以下。中央は終値の単純移動平均、幅は直近 N 本の終値の母標準偏差の K 倍。どのグループでも使える | 2〜500 本、σ 0.1〜5（0.1 刻み） |
| 買値からの % | 判定時の現在値が買値から N% 以上上がった・下がった。売りのグループだけで使える | 0.1〜100% |
| 買ってからの最高値からの %（トレーリングストップ） | 判定時の現在値が、そのロットを買ってからの最高値から N% 以上下がった。最高値が買値から M% 以上になるまでは成立しない（発動。M が 0 なら買った直後から）。一度発動すれば、その後に現在値が買値近くまで戻っても成立する。売りのグループだけで使える | N 0.1〜100%、M 0〜100%（0.1 刻み） |
| 買ってからの本数 | そのロットの買いの約定から、選んだ足で N 本ぶんの時間が経った。売りのグループだけで使える | 1〜1000 本 |
| センチメント / リスクが指定のどれか | 判定時の市場評価（`docs/news-page.md`）が、選んだ値のどれかである。どのグループでも使える。値の末尾に「データなし」も選べ、採点の記録が始まる前（判定がまだ無い）ときに成立する。データなしのとき「データなし」を選んでいない条件は成立しない。記録開始後に集計の期間のニュースが0件のときはデータなしではなく中立の判定（`docs/news-page.md`） | 1つ以上選ぶ |

- RSI の条件を追加するときの既定は、買いでは「14 本が 30 以下」、売りでは「14 本が 70 以上」。RSI のクロスの既定は、買いでは「14 本が 30 を上抜けた（直近 1 本以内）」、売りでは「14 本が 70 を下抜けた（直近 1 本以内）」
- 終値と EMA の位置の既定は、買いでは「200 本より上」、売りでは「200 本より下」。EMA の傾きの既定は「50 本が 5 本前より 0% 以上」で、買いでは上がっている、売りでは下がっている。ボリンジャーバンドの既定は 20 本・2σ で、買いでは下限以下、売りでは上限以上。トレーリングストップの既定は 3%・発動 0%（発動の % を持たない保存済みの条件も 0 で読む）、買ってからの本数の既定は 24 本
- トレーリングストップの最高値は買値を起点に、約定より後に始まった足の高値と、約定した足の終値（約定前の高値を含みうるため高値は使わない。バックテストでは約定時刻と同じ時刻に始まる足も約定した足とみなす）から求める。足は条件の足ではなく、前回の判定から今回までの細かい足（バックテストは進める足、自動取引は1分足）を使う。前回の判定までの最高値は戦略の state に持ち、判定の間に過ぎた足も受け取って取りこぼさない。自動取引をオンにし直すと state が消えるため、それまでの最高値は受け取った足の範囲からしか求め直せない
- 市場評価の条件を追加するときの既定の選択は、買いでは良い側（センチメントは中立以上、リスクは平常・警戒）、売りでは悪い側（強い弱気・危機）

## 注文

- 買いの注文は「買い注文する条件」に行の並び（1〜10 行）で持つ。条件が成立すると、行の数だけ同時に出す
    - 行ごとに指値か成行を選ぶ。成行は1行だけで、先頭に置く。指値と混ぜてよい
    - 指値：現在値から N% 下（0 以上 100 未満、0.01 刻み。円未満は切り捨て）に出す。下の行ほど大きい % にする（同じ値・逆順は保存できない）。指値の行は全件同じ、選んだ足で M 本（1〜100）ぶんの時間のあいだ約定しなければ取り消す。一部が約定しても残りは期限まで置く
    - 成行：判定時の現在値で見積もった注文額に資金が足りなければ出さない。バックテストでは次の足の始値で約定し、その時点で手数料込みの約定額に資金が足りなければ取り消す
    - 空き枠（最大ロット数 − 保有ロット − 未約定の買い）が行の数より少なければ、空きの数だけ先頭から出す
    - 資金は行の順に見積もり、足りなくなった行から先は出さない。未約定の買いの額（手数料込み）は資金から除いて見る。同時に出した買いが先に約定して足りなくなったら、約定時に取り消す
    - 既定は指値・0.1% 下・1時間足で 3 本の1行。行を持たない保存済みの戦略・バックテスト結果は、持っている注文方法の1行として読む
- 買いの注文が1件でも約定待ちの間は、新しい買いを出さない
- 最大ロット数が 2 以上なら、買いの条件が前回の判定で成立していたときは買わない（RSI 30 以下のような条件が続く間に、約定のたびに次を買って枠が埋まるのを防ぐ）。一度外れてから再び成立したら買う。最大ロット数が 1 の戦略には効かせない（今までどおり、売った直後に条件が続いていれば買い直す）
- 売りはロットごとに判定し、成立したロットだけ成行で全量を売る（一部利確だけは一部）
    - 「買値からの %」「最高値からの %」「買ってからの本数」はそのロットで見る。EMA・RSI・ボリンジャーバンド・市場評価の条件はロットに依らないので、成立すると全ロットを売る
    - 同じ判定で複数成り立ったロットは、損切り（建値ストップを含む）> 利確 > 一部利確 の順で1つだけ出す
    - 売りが約定待ちのロットは判定しない
- 一部利確
    - 一部利確の条件が成立したロットは、ロットの N%（1〜99 の整数。1 satoshi 未満は切り捨て）を売る。既定は 50%。1ロットにつき1回だけで、売った後の残りには利確・損切りの条件が効く
    - 売る量と残りは、どちらも注文量の下限（0.001 BTC）以上にする。1回の注文量との組み合わせで下回る割合は保存できない
    - 建値ストップ（既定はする）: 一部利確の後、判定時の現在値が買値を下回ったら、残りを損切りとして売る。損切りの条件とは別に効く。手数料があるので、この売りの損益は少しマイナスになる
    - 一部利確の条件が空なら使わない。売る割合・建値ストップを持たない保存済みの戦略は既定で読む
    - 成績の数え方は `docs/trading.md`（買い1件ごとに1往復）
- 同じ判定で売りと買いが両方成立したら両方出す。空き枠は売る前の保有で数え、売りで空く枠は次の判定から使う
- 判定の間隔は、ロットを1つでも持っていれば「保有中」を使う

## リスク上限

- その日（JST 0:00 区切り）に売って確定した損益（手数料込み）の損が1日の損失上限に達したら、新しい買い注文を出さない。翌 0:00（JST）に再開する
- 含み損は数えない。売り（利確・損切り）は止めない。自動取引はオンのまま
- 戦略の条件とは別に、売買の1ステップ（`docs/trading.md`）の中で注文を出す手前で検査する。バックテストにもペーパーにも同じように効く
- 買いを止めた理由は判断の記録に残す
- 損切り後に買わない本数が 1 以上なら、損切りの売り（建値ストップを含む。利確・一部利確は含まない）を出した判定の時刻から、選んだ足でその本数ぶんの時間は新しい買いを出さない。ロットを問わず戦略全体で止める。同じ判定で損切りと買いが両方成立したときも買わない
    - 1日の損失上限と違い、戦略の判定の中で見る。損切りの時刻は戦略の state に持つので、自動取引をオンにし直すと消える
- 同時の保有は「1回の注文量 × 最大ロット数」までに収まるので、保有量の上限は別に持たない。急落で全ロットが同じ判定で損切りされると、1日の損失上限を1回で大きく超えることがある

## ひな形

新しい戦略は、ひな形（空の戦略・トレンド追随・レンジ逆張り）か、保存済みの戦略の複製から作る。ひな形の最大ロット数は 1。買いの注文はトレンド追随だけ成行の1行（上抜けで買うため、指値では取り逃がしやすい）、ほかは既定の指値の1行。作った後はひな形・複製元と切り離される。

## 保存

- 名前は 1〜40 文字で、戦略どうしで重複できない
- 条件は入力検証を通ったものだけ保存できる
- 削除しても過去のバックテスト結果は残る

## 運用する戦略

- 保存済みの戦略から1つを「運用する戦略」に選ぶ。未選択でもよい。サーバーに保存する
- 運用する戦略を削除すると未選択に戻る
- 自動取引がオンの間と、口座に保有か未約定の注文がある間は、運用する戦略の条件の変更・切り替え・削除をできなくする（API は 409）。名前の変更とコピーはできる。保有はオフにしても口座に残り、オンにし直すと同じ戦略で売るため。戦略の画面では入力を押せなくし、理由と「コピーして編集する」を出す
- ホームのチャートの EMA・RSI・ボリンジャーバンドの既定の本数と、自動取引に使う
