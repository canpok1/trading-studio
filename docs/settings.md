# 設定画面

設定画面（`/settings`）は、メニューに合わせた区分（全般・バックテスト・ニュース。並びもメニューと同じ）に分ける。複数のメニューで使う設定は「全般」に置く。表示中の区分は URL（`?section=`、全般なら無し）に持つ。

## 全般

- 画面の色（OS に合わせる・ライト・ダーク）。選んだ設定はブラウザに保存する
- Gemini の API キー: 設定済みか未設定かと保存した日時だけを出し、キーそのものは出さない。入力は伏せ字。上書きと削除（確認あり）ができる
- データの保持: 古いデータを消すまでの期間（判断の記録・バックテストは 30・90・180・365・730日・無期限、足・ニュース・採点は 1・2・3・5・10年・無期限）。「データの保持」に詳しく書く

## データの保持

DB の肥大化を防ぐため、毎日 4:00（JST）に保持期間を過ぎたデータを消す。サーバーの起動時に前回から実行時刻を過ぎていれば1回実行する。前回の削除を記録していなければ、起動した後の最初の 4:00 に実行する。

| 対象 | 既定 | 消し方 |
|---|---|---|
| 判断の記録（自動取引） | 90日 | 判断した時刻が期間より前のものを消す。注文を出した判断は、注文の詳細の「そのときの判定」に使うので消さない |
| バックテストの実行 | 無期限 | 実行を始めた時刻が期間より前のものを、結果・アドバイスごと消す。実行中とアドバイスの生成中は消さない |
| 足・ニュース・採点 | 5年 | 1分・5分・15分足と、公開時刻が期間より前のニュースを採点・採点し直しごと消す。1時間・4時間・日足は小さいので残す。開始が期間より前の相場データは相場ごとに最新の1件だけ残して消し、残した相場データの開始の31日前から終了までの足（全粒度）とニュースは消さない（指標の計算と市場評価で期間より前を使うため） |

- 自動取引の注文は成績に使うので消さない
- 足・ニュースの期間は年で数える（実行した時刻の N 年前）。1年分の足は全粒度で約57MB、うち約78%が1分足（`docs/adr/0025`）
- ニュースを消した境目を覚え、境目の31日後までは市場評価の記録が無いものとして扱う（遡って使う記事が欠けているため。`docs/backtests.md`）。残した相場データで実行するときは、その相場データの開始から記録があるものとする。消している途中で止まっても扱いが変わらないよう、境目は消す前に覚える
- ニュースを消した期間（開始の31日前が境目より前の期間）は、足を取り込み直しても相場データにしない
- 足を消した期間はインポート画面で欠損として出る
- 消した期間の判断の記録は分析用エクスポートに出ない
- カードに次回と前回の削除（日時・件数・失敗の理由）、DB の大きさ、テーブルごとの行数を出す
- 消しても DB ファイルは縮まない。空いた領域は次の書き込みで再利用され、ファイルがそれ以上大きくならない。縮める処理（VACUUM）は、実行中に他の書き込みを止めてしまうので行わない
