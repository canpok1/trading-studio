# 0006. 判定頻度が足の粒度より短い戦略は、バックテストで細かい足を使って判定する

- ステータス: 採用
- 日付: 2026-09-26

## コンテキスト

戦略は足の粒度と、ポジションなし・ありの判定頻度を別々に持つ（例: 1時間足・ポジションあり15分ごと）。バックテストのエンジンは戦略の粒度の足の終わりにしか判定しておらず、1分足を取り込んでいても1時間ごとにしか判定しなかった。画面には「15分ごと」と出るので、設定と結果がずれる。ペーパー・ライブは判定頻度どおりに判定するため、バックテストだけ動きが違うと結果を比べられない。

## 決定

- 両方の判定頻度を割り切れる粒度のうち最も粗いもの（戦略の粒度が上限）を判定の足にし、その足で約定と判定を進める
- 判定のときに戦略へ渡す足は、確定した戦略の粒度の足と、細かい足から組み立てた途中の足。現在値は細かい足の終値。戦略の型は変えない
- 期間にその粒度の足が無ければ、取り込み済みの最も細かい足で進め、実行画面と結果に判定頻度より粗い間隔でしか判定できないことを出す（2026-09-26 ユーザー判断）

## 結果

- 設定どおりの頻度で損切り・利確を判定できる。チャートの足は戦略の粒度のまま
- EMA は途中の足の終値を含めて計算するため、足の途中でクロスが成立し、足の終わりには解消していることがある
- 細かい足の本数だけ計算が増える

## 検討した代替案

- 警告だけ出し、判定は足の終わりのまま：設定と結果のずれが残り、ペーパー・ライブと比べられない
- 足の粒度より短い判定頻度を入力できなくする：ライブで細かく判定したい使い方ができなくなる
- 指標は確定した足だけで計算し、現在値だけ細かい足から渡す：戦略の入力に現在値を足す変更が要る。直近の高値・安値の突破は今の足を除いて見るため、途中の足を渡す形でも意味が変わらない
