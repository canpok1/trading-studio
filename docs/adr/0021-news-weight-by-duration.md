# 0021. 市場評価の重みを記事ごとの持続で減らし、関係ない観点は 0 点にそろえる

- ステータス: 採用
- 日付: 2026-10-05

## コンテキスト

市場評価は期間（既定 24 時間）内の記事の点数を、全記事共通の半減期（既定 6 時間）で重み付けして平均していた。規制発表も単発の発言も同じ速さで効かなくなるのは不自然だという指摘があった（利用者）。また、関係ない観点を null にし、計算の都合で「評価なし」と 0 点を区別していたのも分かりにくかった（利用者）。

## 決定

- AI が記事ごとに影響の持続（none・short・medium・long。画面では なし・短期・中期・長期）を1つ付ける。観点ごとには付けない
- 評価ルールは持続ごとの半減期を持つ（既定 短期 6・中期 24・長期 72 時間）。記事は半減期の4倍たったら集計から外す。評価ルールの「期間」はなくす
- 集計に使うかは重みで決める。重み 0%（持続 none・半減期の4倍より前）の記事は平均に入れず、それ以外は入れる
- null を廃止し、関係ない観点は 0 点にする。持続 none の記事は両観点とも 0 点
- 過去の採点はマイグレーションで、null を 0 点にし、両観点とも null なら持続 none、ほかは short にする。古い形の評価ルールは、その半減期を短期とし中期・長期は既定値で読む
- 画面の名前は「持続」。ニュース一覧ではチップに「持続 長期」を出し、重みは公開時刻・取得元の行の右端に出す

## 結果

- 片方の観点だけ関係ない記事は、その観点が 0 点として平均に入る。9/6〜10/5 のデータでは採点済み 344 件中 7 件だけで、影響は小さい
- 半減期の違う記事が混ざる間は時刻とともに平均が動くので、バックテストの判定はその間、評価のたびに計算し直す
- 集計に使う一番長い長さ（既定 12 日）まで遡って記事を読み、採点もそこまで古い記事を対象にする
- 過去の記事に持続を付けるには、新しい版で採点し直す。付けるまでは短期として扱うので、古い版の結果はほぼ今と同じ（期間が半減期の4倍でなかった評価ルールだけ変わる）

## 検討した代替案

- 観点ごとに半減期をルールで持つ（AI は変えない）: 記事ごとの寿命の違いを表せない
- 持続を観点ごとに付ける: AI の出力が増えてぶれの元が増える。まず1つで効果を確かめる
- 段階ごとに期間も設定する: 設定が6つになり、半減期と別に調整する必要が薄い
- 期間は共通の 24 時間のまま: 長期の記事も 24 時間で消え、長く効かせられない
- 持続の無い過去の採点を中期として扱う・採点し直しを必須にする: 古い版の結果が変わり、新しい版と比べる基準にならない
- 0 点を平均に入れない（0 点＝材料なし）: 「重み 0% なら対象外」の1つの決まりにまとめるほうが分かりやすい（利用者の案）
- 名前を「インパクト」にする: 影響の大きさと読め、ニュースの絞り込み「影響の大きさ」と紛らわしい
