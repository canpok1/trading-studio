# 0034. 保持の削除を全粒度で同じ条件にし、残す相場データの前は粒度ごとに必要な本数を残す

- ステータス: 採用
- 日付: 2026-10-18

## コンテキスト

設定「足・ニュース・採点」の年数による削除は、1分〜15分足とニュースを消し、1時間・4時間・日足は残していた（`0025`）。境目より前でも相場の種類ごとに最新の相場データを1件残し、その開始の31日前から終了までは全粒度を残す。DVOL の保持（`0032`）を決める中で、利用者がこの仕様を見直した（Issue #243）。

## 決定

- 全粒度の足を同じ条件で消す。`0025` の「1時間足より粗い足は残す」を置き換える。根拠: 削除の仕様をシンプルにしたい（利用者）
- 境目より前でも、相場の種類ごとに最新の1件に加え、データセットに入っている相場データを残す。根拠: データセットに入れた期間が知らないうちに消えるのを避けたい（利用者）
- 残す相場データの前は、足と DVOL を粒度ごとに「上限で必要な850本（`0033`）」と31日の長いほう、ニュース・採点を31日残す（1時間足36日、4時間足142日、日足850日）。根拠: 指標の上限で必要な相場データを残したい（利用者）

## 結果

- 境目より前の期間は、残した相場データ以外ではバックテストできなくなる
- チャートで境目より前の足が出なくなる
- 残した相場データでは、上限内の指標を不安定期間ぶん遡って計算できる

## 検討した代替案

- 1時間足より粗い足は残す（`0025` のまま）: 削除の仕様がシンプルでない
- 残す前の範囲を全粒度31日のまま: 1時間足以上の長い指標で前の足が足りない
- データセットに入っているかを見ない（今のまま）: 入れた期間が知らないうちに消える
