# 0004. 実取引を始めるまでは自宅 LAN 内へ公開し、Tailscale は実取引の前に入れる

- ステータス: 採用
- 日付: 2026-09-26

## コンテキスト

ADR 0003 ではホストの `127.0.0.1:3000` にだけ公開し、Tailscale Serve で開くと決めた。しかし実取引はフェーズ5まで無く、それまでは画面を誰に操作されても動くのは仮想の取引だけになる。Tailscale の導入とログインを今やる手間に見合わない。

## 決定

- 実取引を始めるまでは、コンテナをホストの `3000` 番ポートで全インターフェースに公開し、自宅 LAN 内から HTTP で開く
- 実取引（Issue #10）に着手する前に、Tailscale 経由だけで開ける形へ切り替える
- インターネットへは公開しない（cloudflared やルーターのポート転送を使わない）という方針は変えない

## 結果

- mini-pc 側に Tailscale の設定が要らず、スマホから LAN 内アドレスで開ける
- 自宅 LAN につながる端末なら誰でも操作できる。影響はペーパーの仮想取引と設定に限られる
- 外出先からは開けない
- 通信は暗号化されない。API キーを画面から入力する機能を作る場合は、その前に切り替える

## 検討した代替案

- 今のうちに Tailscale Serve で開く（ADR 0003）：実取引が無い段階では守る対象が無く、導入の手間が先に立つ
