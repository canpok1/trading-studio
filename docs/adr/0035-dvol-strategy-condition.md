# 0035. DVOL を戦略の条件にし、見方は直近の平均との比（既定）と値の2つにする

- ステータス: 採用
- 日付: 2026-10-18

## コンテキスト

`0032` で DVOL の収集を決め、戦略の条件・バックテストで使うかは別に決めるとした。利用者が DVOL を戦略の条件に使いたいと依頼した。DVOL の水準は年で大きく違う（日足の中央値は 2021 年が約 90、2026 年が約 40）。利用者の依頼で判断の仕方を調べた（2021〜2026 年の1時間足）。どの見方でも次の24時間の方向は当たらず、値動きの大きさは当たる。前年に決めたしきい値を翌年に当てると、固定の値は年によって発動率が 0〜41% と大きく変わり、直近の平均との比とパーセンタイルは毎年 13〜34% 発動して発動中の値動きは 1.2〜1.6 倍だった。

## 決定

- 見方は「直近 N 日の平均との比」（既定）と「値」の2つにする。根拠: 上記の調査の結果を見て選んだ（利用者）
- 買い・一部利確・利確・損切りのどのグループでも使えるようにする。根拠: どれにでも使いたい（利用者）
- DVOL が無いとき（取得が止まっている・過去分が無い）は条件を成立させない。根拠: 今後はデータがあるはずで、無いときは買わないほうが安全（利用者）

## 結果

- DVOL の条件は自動取引・見張り・バックテストで同じように判定される
- DVOL が無い期間は、DVOL の条件を入れた買いが発動しない
- 方向は当たらないので、リスクを下げる使い方（荒れそうなときは買わない・荒れ始めたら手仕舞う）向き

## 検討した代替案

- 値だけ: 年によって効き方が大きく変わる
- 平均との比だけ: 値は残す
- 365 日パーセンタイルも足す: DVOL の保持（`0032`・`0034`）を変える必要がある
