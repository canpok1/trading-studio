# 0018. 足は戦略ではなく条件ごとに持ち、チャートの粒度は戦略から決めない

- ステータス: 採用
- 日付: 2026-10-01

## コンテキスト

戦略は足を1つ持ち、全条件がその足で判定していた。日足でトレンドを見て1時間足で入るような、複数の足を組み合わせる戦略を作りたいという要望が出た（利用者の要望）。

## 決定

- 戦略の足をやめ、本数で数える項目（条件・指値の取消・損切り後に買わない本数）がそれぞれ足を持つ。既定は1時間足。以前の戦略は戦略の足で読む
- バックテストは条件で使う最も細かい足まであれば実行し（0006 を足ごとに広げる）
- チャートの既定は日足。選んだ粒度をブラウザに保存し、ホームとバックテスト結果で共有する

## 結果

- 判定の文・バッジに足が付く
- 結果は日足だけ保存し、チャートは選んだ粒度で期間のデータを読み直す。ガチホの損益率は実行時に保存する

## 検討した代替案

- 戦略の足を残し、条件で上位足を追加で選ぶ: どちらの足で数えるかが項目ごとに分かりにくい
- 買ってからの本数などを時間で持つ: 「日足で5本」と足で考える方が条件と揃う（利用者が選択）
- チャートの既定を条件の足に合わせる: 条件ごとに足が違い決まらない。画面で変えられるので割り切る（利用者が選択）
