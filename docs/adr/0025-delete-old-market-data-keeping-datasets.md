# 0025. 古い足・ニュース・採点は5年で消し、期間を過ぎたデータセットは相場ごとに最新だけ残す

- ステータス: 採用
- 補足: ここでの「データセット」（2か月の期間）は `0026` で「相場データ」に改名した
- 日付: 2026-10-08

## コンテキスト

足・ニュース・採点は、バックテストの材料として消さない方針だった（`docs/settings.md`）。利用者から、データの肥大化が気になるので期間を設定して消したい、既定は5年、ただし相場ごとのデータセット（`0024`）は5年を過ぎても使いたいという要望があった。

今の足の表で1年分（1分足〜日足の全粒度、約68万行）を入れて測ると約57MB、うち約78%が1分足だった。データセット1件（2か月）の足は約9.5MB。

## 決定

- 設定の「データの保持」に「足・ニュース・採点」の年数（1〜20年・無期限、既定5年）を足す。毎日 4:00 の削除で、実行時刻の N 年前を境目にする
- 足は 1分・5分・15分足だけ消す。1時間足より粗い足は5年で約1.5MBなので残し、長い期間のバックテストに使う
- ニュースは公開時刻が境目より前のものを、採点・採点し直しごと消す
- 開始が境目より前のデータセットは、相場ごとに開始が最も新しい1件だけ残して消す。残したデータセットの開始の31日前から終了までの足（全粒度）とニュースは消さない。市場評価は公開から長期の半減期の4倍（既定12日）まで遡って記事を使い、指標は期間より前の足で計算し始めるため、余裕をもって31日にした
- ニュースを消した境目を覚え、境目の31日後までは市場評価の記録が無いもの（記録の始まりより前と同じ扱い）とする。遡って使う記事が欠けているため。残したデータセットで実行するときだけ、その開始から記録があるものとする。境目は消す前に覚え、途中で止まっても欠けた期間を記録として扱わない
- ニュースを消した期間は、足を取り込み直してもデータセットにしない

## 結果

- 足は5年分の約290MBで頭打ちになり、残すデータセットのぶん（開始の31日前から含めて1件約14MB、相場4種で最大約57MB）が上乗せになる
- 消した期間の1時間足は残るが、市場評価の条件がある戦略は「データなし」を選ばないとその期間で実行できない。黙ってニュース無しで実行されることはない
- 足を消した期間は欠損として出る
- 消した期間のバックテストは結果を見られるが、細かい足で再実行はできない

## 検討した代替案

- 全粒度の足を消す: 粗い足は小さく、残せば長い期間のバックテストに使える
- データセットをすべて残す: 毎月作るので全期間が守られ、足が消えなくなる
- 残すニュースを評価ルールの今の長さぶんだけ前からにする: 後で長期の半減期を延ばすと、期間の初めの評価がずれる
- 足とニュースで保持期間を分ける: データセットで残す範囲がずれ、設定が増える。分ける必要が出てから分ける
- ニュースを消した境目を覚えず、最初の採点の時刻だけで記録の始まりを決める: 残したデータセットの古いニュースが記録の始まりになり、消した期間でもニュース無しのまま実行できてしまう
