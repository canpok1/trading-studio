# 0032. Deribit の DVOL を1時間足で収集し、足と同じ条件で消す

- ステータス: 採用
- 日付: 2026-10-17

## コンテキスト

利用者が BTC/JPY の値動きの予想に使うデータソースを探しており、2026-01〜10 の1分足で今の取得元（ニュース3紙・FX カレンダー）と代替候補を検証した。方向を当てられるデータは無く、値動きの大きさの予想には Deribit の DVOL（BTC オプションから計算した30日の予想ボラ）が候補の中で最も効いた。Deribit の API はキー不要で、1時間足は 2021-03 から取れるが、1分足は直近しか取れない。

## 決定

- DVOL を Deribit の API から収集して保存する（Issue #242）。根拠: 値動きの大きさの予想に最も効く（利用者）
- 収集の最小単位は1時間足にする。根拠: 過去分まで取得できる最小単位（利用者）
- 保持は設定「足・ニュース・採点」の年数に従い、足と同じ条件で消す（残した相場データの範囲は残す。足の削除は `0033`）。根拠: 価格が無い期間に DVOL だけあっても使えない。データの肥大化を防ぐため一律で消したい（利用者）

## 結果

- 取り込んだ過去分の DVOL をチャート・MCP・分析 ZIP で見られる。戦略の条件・バックテストで使うのは別に決める
- 足を消した期間の DVOL も消えるので、DVOL だけが残る期間はできない
- 1時間より細かい DVOL の動きは扱えない

## 検討した代替案

- 1分足でも収集する: 過去分が取れない
- DVOL は消さずに残す: 上記の保持の根拠のとおり
