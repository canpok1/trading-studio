# 0008. ニュースは規約上の問題が少ない日本語の RSS 3つから15分おきに集め、Gemini 3.5 Flash-Lite で採点する

- ステータス: 提案（既定の取得元とモデルはユーザーの選択待ち。推奨案で実装している）
- 日付: 2026-09-26

## コンテキスト

フェーズ3で、ニュースを RSS で集めて Gemini に採点させ、相場の判定に使う。既定の取得元と採点に使うモデルを決めるため、候補の RSS・利用規約・Gemini の料金を調べた（2026-09-26。RSS は実際に取得、Gemini は ai.google.dev の一次資料で確認）。

取得元の候補（件/日は推定）:

| 取得元 | 件/日 | 規約 |
|---|---|---|
| NADA NEWS（旧 CoinDesk Japan） | 約10 | 禁止はサーバーの妨害・目的外利用のみ |
| あたらしい経済 | 約12 | 利用規約のページが無い |
| NHK 経済 | 約10 | 個人利用は可 |
| CoinPost | 約16 | 複製・二次利用を禁止 |
| CRYPTO TIMES | 約15 | 第三者への送信を禁止 |
| Cointelegraph・The Block | 4〜17 | AI での利用を明示的に禁止 |
| CoinDesk・Decrypt | 約17 | 自動手段でのアクセス・保存を禁止 |
| Bitcoin.com・Bloomberg | 12〜22 | 未確認 |

どれも全記事に見出し・概要・公開時刻がある。

Gemini（1件 入力600・出力150トークン、1日約120件で見積もり）:

- gemini-3.5-flash-lite: $0.30 / $2.50（100万トークンあたり入力 / 出力）、月約 $2
- gemini-3.8-flash: $0.75 / $3.75（2027年から $1.50 / $7.50）、月約 $3.6（2027年から約 $7.3）
- gemini-3.1-pro-preview: Preview のみ、$2 / $12、月約 $11
- 無料枠のキーでは、送った入出力が製品改善に使われ、人がレビューしうる
- 呼び出し回数の上限（RPM / RPD）の公式値は確認できていない

## 決定

- 既定の取得元は NADA NEWS・あたらしい経済・NHK 経済の3つ。英語の取得元は既定に入れない（画面から追加はできる）
- 収集の間隔は既定15分、画面で5〜1440分に変えられる
- 採点の既定モデルは gemini-3.5-flash-lite。画面で gemini-3.8-flash・gemini-3.1-pro-preview に替えられる
- API キーは有料枠のものを使う（無料枠だと記事が学習に使われる）

## 結果

- 規約で禁止されていない取得元だけで始められる。1日約30件
- 英語圏のニュースが入らないので、海外発の材料は日本語の記事になるまで判定に入らない
- 月の費用は数ドルに収まる見込み。採点のぶれが大きければ画面から上位のモデルに替える
- 実際の Gemini の呼び出しは、この実行環境に API キーが無いため確かめていない

## 検討した代替案

- 英語の CoinDesk・Decrypt も既定に入れる: 件数と速報性は増えるが、規約の自動取得・保存の禁止に触れうる
- gemini-3.8-flash を既定にする: 採点の質は上がる見込みだが、費用が約2〜4倍で、思考トークンの分だけさらに増えうる。見出しと概要だけの採点には軽いモデルで足りると判断した
