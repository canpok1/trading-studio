# 0013. MCP からニュースの採点の基準の版を保存し、使用する版を切り替えられるようにする

- ステータス: 採用
- 日付: 2026-09-28

## コンテキスト

Claude Code から、ニュースの AI 採点が値動きと合っていたかを分析し、採点の基準（プロンプトのうち編集できる部分）を調整したい。ADR 0012 は MCP に設定を変える道具を出さないと決めている。採点の基準は設定の一つで、使用する版を切り替えると以後の判定と、それを条件に使う自動取引に効く。

## 決定

- MCP に、採点と判定をその後の値動きと突き合わせる読み取りの道具と、過去のニュースを基準の案で採点し直す試し採点（保存しない）を足す
- 基準の新しい版の保存と、使用する版の切替も MCP から行えるようにする（利用者の判断、2026-09-28）。ADR 0012 の「設定は道具にしない」の例外とする
- 切替の道具の説明と MCP の instructions に、切り替える前に利用者へ確認を取るよう書く
- 集計ルール・モデル・API キーなど、ほかの設定は引き続き道具にしない。集計ルールは案を渡して試算するだけにする

## 結果

- 分析から調整・反映までを Claude Code の中で完結できる
- Claude Code が利用者の確認なしに切り替えると、次に採点するニュースから判定が変わる。採点は版ごとに記録され、画面から前の版へ戻せる。採点済みのニュースは採点し直さないので、切り替える前の記録は変わらない

## 検討した代替案

- 版の保存までを MCP で行い、切替は画面で人が行う: ADR 0012 の線を保てるが、分析のたびに画面を開く手間が残る。利用者が MCP での切替を選んだ
