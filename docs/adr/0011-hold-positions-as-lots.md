# 0011. 保有を買い1件ごとのロットで持ち、売りはロットごとに判定する

- ステータス: 採用
- 日付: 2026-09-27

## コンテキスト

これまでポジションは1つだけで、ポジションが無いときしか買わなかった（フェーズ1の判断）。レートの急変に合わせて価格の違う指値を同時に出し、約定した買いごとに利確・損切りしたいという要望が出た。1ポジションの前提は、売買の1ステップ・口座の保存形式・成績の数え方・1日の損失上限の考え方（上限は注文量と同義）に入っている。

## 決定

約定した買い1件を1ロットとして口座に並べ、平均買値へ合算しない。売りの注文は売るロットを指定し、往復・成績はロット単位で数える。戦略には最大ポジション数（既定 1）と買い注文の行の並びを持たせる。旧形式の口座・戦略は1ロット・1行として読む。

## 結果

- 既定の最大ポジション数 1 では今までと同じ注文になる
- 同時の保有は最大で「注文量 × 最大ポジション数」になり、1日の損失上限を1回の急落で大きく超えうる（ユーザー了承済み）
- 口座の JSON の形が変わるため、保存済みの口座は読み替えが要る

## 検討した代替案

- 1ポジションのまま買い増し、平均買値で売る: 作りは小さいが、買いごとに売れず要望を満たさない
- 戦略ごとに独立したサブ口座を複数持つ: 資金の配分と画面が複雑になり、1つの戦略で階段を出す用途には過剰
